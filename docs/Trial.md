# 合成样本试用

测试对下列 10 份合成样本生成真实脱敏输出，自动验证预期敏感项已替换且诊断线索仍在。6 份 SQL 均可通过本次映射还原。表中的下一步是基于脱敏输出的离线分析，发布前仍需用执行计划、日志或环境数据验证。在测试环境中设置 LOCAL_REDACTOR_SHOW_TRIALS=1 可以查看脱敏样本。

| 样本 | 脱敏后保留的线索 | 可继续分析的方向 |
| --- | --- | --- |
| 日期过滤 | TRUNC、日期列和绑定条件 | 对照执行计划，评估等价日期范围过滤 |
| 关联过滤 | 关联键、过滤列、两个来源之间的关系 | 检查驱动行数、过滤选择性和关联索引 |
| 相关子查询 | EXISTS 和内外层关联列 | 检查执行计划是否对 EXISTS 使用半连接，以及关联列的访问方式 |
| 窗口函数去重 | 分组键、排序键和排名条件 | 检查排序成本，确认相同时间戳时需要什么确定的排序规则 |
| CTE 预聚合 | 聚合函数、分组列、聚合后的过滤条件 | 检查聚合前后行数和是否有可提前过滤的条件 |
| 重复记录 | 两个分支的相同过滤，以及 UNION | 确认是否需要去重，再评估集合运算开销 |
| Oracle 监听 | ORA-12541、no listener、端口 | 核对监听状态、应用目标与端口 |
| 连接池耗尽 | active、idle、获取连接的超时时间 | 追踪连接占用时长、泄漏或池配置 |
| HTTP 鉴权 | HTTP 401、invalid_token | 检查凭据有效期、刷新行为和令牌配置 |
| SQL 异常栈 | ORA-01017、JDBC 协议、调用位置 | 检查应用读取凭据的来源和连接配置 |
