# 本地脱敏中转站设计

macOS 14+ 的纯文本工具，面向把 Oracle 查询和报错日志交给 AI 分析的开发者。菜单和全局快捷键载入剪贴板，预览检测结果并允许手动补遮盖，用户确认后复制。AI 回复走单独的入口预览和还原。应用无网络能力，无后台剪贴板采集，无持久化文本。

## 文本处理

SQL 模式只接受单条 Oracle SELECT，含显式 JOIN、逗号连接、嵌套查询、普通 WITH、集合运算及双引号标识符。按查询作用域标记 schema、对象、CTE、表别名和相关限定引用，保留格式、列名、绑定参数及公开的 DUAL。非引号标识符按 Oracle ASCII 大写规则比较。普通注释去除内容并保留断行。Hint、DB Link、语法破损及语法范围之外的查询禁止复制。普通字面量和列名由用户按需补遮盖，SQL 字符串中的 IP 和符合规则的密钥自动处理。界面始终显示识别边界。

日志模式识别 IPv4、IPv6、Authorization、常见凭据字段、可辨格式的令牌、URL 凭据和私钥块。保留错误码、时间戳和堆栈。规则按命中范围操作，发生交叠时优先不可逆遮盖。手动选择优先并可撤销。引擎的输入是模式、原文、手动选区及本次标识，输出包含替换文本、可视高亮范围、还原表或带位置的安全诊断。纯引擎不接触文件、剪贴板或网络。

## 状态与生命周期

不同输出带随机会话标记。同值按语义复用本次占位符。只在复制脱敏成功后建立本次还原状态，保留 30 分钟。新复制、到期、手动清除或退出销毁旧状态；预览取消不清除已有会话。原文和脱敏预览随窗口关闭释放。密钥与手动覆盖不进入映射。还原只匹配完整占位符；对未知、疑似改动或本次未出现的占位符发出可复核提示。还原复制前再次检查会话有效。写入剪贴板使用当前设备限定，无复制原文入口。

## 本地交付

SwiftPM 管理纯引擎、测试和 macOS 入口。CLI 工具链编译后生成当前架构的应用包并以 App Sandbox 权限签名。本地 UI 用 AppKit 菜单栏、粘贴板和热键接入，SwiftUI 渲染预览。磁盘上唯一应用设置是热键偏好。输入限制为 256 KiB，异步预览避免阻塞界面，100 KiB 日志从读取剪贴板到预览窗口完成布局的 P95 目标为 300 ms。

## 增强预览

Oracle SQL 和日志都提供可选邮箱、明确出现在 URL 中的主机名遮盖。协议、端口、路径和 URL 分隔符保留。邮箱与主机名可通过同一份内存映射还原。URL 中的用户信息视为凭据并永久遮盖。Oracle SQL 另提供字符串内容永久遮盖，保留 Oracle 引号及绑定变量。新增规则默认关闭，只保留在当前预览。

原文选区既可只遮盖一次，也可按字面匹配遮盖文中所有相同内容。一次批量操作通过一次撤销恢复。搜索和脱敏在后台进行。选择附带 AI 提问时，预览展示实际要复制的模板和脱敏正文，SQL 模式提供优化提问，日志模式提供诊断提问。模板独立于本地映射。
